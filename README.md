# C Programming Fundamentals

**Learning C, one problem at a time.**

## About This Repository

I'm a first-year Computer Engineering student at the Polytechnic Institute of Portalegre, Portugal.

This repository documents my journey into programming with C, from understanding how programs work to developing algorithms and solving increasingly complex problems.

My goal is not only to learn the syntax of a programming language, but also to develop the logical thinking and problem-solving skills needed to design efficient, readable and reliable programs.

I'll be using this space to share original exercises, small projects, experiments and improvements as I progress through my studies.
